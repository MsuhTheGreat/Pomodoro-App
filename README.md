# **🍅 Pomodoro Timer App**
A sleek and functional desktop app that brings the Pomodoro Technique to life using Python and Tkinter. This timer helps you stay focused, track your progress, and build better work habits.

## **🔧 Features**
- ✅ 25-minute focus sessions (Pomodoros)

- ☕ 5-minute short breaks

- 🛌 20-minute long breaks after 4 Pomodoros

- 🔔 Bell sound when a session starts/ends

- 🪟 Auto-focuses the window during breaks

- ✅ Visual progress tracking with checkmarks

- 🎨 Minimalist, distraction-free UI

## **🚀 Getting Started**
### **1. Install Python (if not already installed):**
Get it from [python.org](https://www.python.org).

### **2. Install Git (if not already installed):**
You have to install git to be able to clone the files. Install it from [git-scm.com](https://git-scm.com/downloads)

### **3. Clone the Project**
Clone the files by running the following command in your terminal:
```
git clone https://github.com/MsuhTheGreat/Pomodoro-App
cd Pomodoro-App
```

### **4. Run the App**
In your terminal or command prompt, execute the following command:
```
python main.py
```

## **🧠 How It Works**
The Pomodoro cycle is structured as follows:

- 1 Pomodoro = 25 minutes of focused work

- Short break = 5 minutes (after each Pomodoro)

- Long break = 20 minutes (after 4 Pomodoros)

The app manages everything automatically — just click Start and focus. Each completed Pomodoro adds a checkmark under the timer.
